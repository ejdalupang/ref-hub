# Ref Hub

A personal Pinterest-style board for visual references, with tags by Keyword, Style, Trend, Brand (plus any categories you add).

- Static site (no build). Hosted on GitHub Pages.
- Data: `data/hub.json`. Images: `images/`.
- Adding/editing in the browser commits straight to this repo via the GitHub API, so phone and laptop stay in sync.
- Each device needs a one-time fine-grained token (Contents: read & write, this repo only) pasted into ⚙ Settings. It is stored only in that browser.
